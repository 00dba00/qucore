PROD

Production gets a second look

  • On a connection marked prod, every write asks for confirmation first. Plain SELECT runs straight away.
  • An UPDATE or DELETE without WHERE, and TRUNCATE, need an extra tick on any connection.
  • A saved query started on a different database than it was written for asks before it runs.
  • Turn auto-commit off to check your changes, then Commit or Rollback. Closing a tab never drops an open transaction silently.

Each check can be switched off in Settings, and Settings tells you what you would risk.
